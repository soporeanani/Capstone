# Conflict Networks: Time-Varying Connectedness of US Sector ETFs Under Geopolitical Risk

## How to run
1. [Open the data cleaning notebook (Python)](https://colab.research.google.com/github/soporeanani/Capstone/blob/main/notebooks/01_data_cleaning.ipynb)
2. [Open the spillover analysis notebook (R)](https://colab.research.google.com/github/soporeanani/Capstone/blob/main/notebooks/02_spillover_analysis.ipynb)

The cleaned data is included, so the analysis notebook can be run on its own. In Colab, select **Runtime > Run all**.

The raw files are not included, so the cleaning notebook shows the process and saved outputs but cannot be rerun from this repository.

Data source: Stooq, last downloaded November 1, 2026.
